## 2. Copywriting Constraints and Compliance Checklist

All draft variations adhere strictly to the following parameters:

- **Hook Character Limit:** <= 80 characters on line 1 (ensures zero cutoff on mobile view before the "more" trigger).
- **Hook Emoji Count:** Maximum 2 emojis situated at the end of the sentence.
- **Register & Pronouns:** Indonesian Gen-Z casual register (`lo`, `gw`), prohibiting stiff pronouns (`aku`, `kamu`).
- **Objective Stance:** Zero personal usage claims (`saya/aku/gw sudah pakai` is strictly absent). Claims rely on formulation science, ingredient functions, and objective behavioral observations.
- **Anti-Spam Tone:** Zero spam trigger words (`diskon gila`, `promo termurah`, `beli sekarang juga`).
- **Formatting Standards:** Standard Markdown bullets (`-` or `1.`). Zero emoji bullets. Zero AI fluff words (`seamlessly`, `elevate`, `leverage`, `empower`, `next-generation`, `delve into`).

Run this test script to verify that character counts, anti-spam tone, register constraints, and objective statements strictly conform to the engineering standards.

import re

HOOKS = [

]

FORBIDDEN_WORDS = [

    "delve into", "in today's fast-paced world",
    "diskon gila", "promo termurah", "beli sekarang juga",
    "aku", "kamu"
]

FORBIDDEN_PERSONAL_CLAIMS = [
    "sudah pakai", "udah pakai", "udah coba", "saya pakai", "gw pakai", "gue pakai"
]

def validate_copywriting():
    for idx, hook in enumerate(HOOKS, 1):
        # 1. Length check <= 80 characters
        length = len(hook)
        assert length <= 80, f"Hook {idx} exceeds 80 characters: {length}"
        
        # 2. Max 2 emojis at end of sentence
        emojis = [c for c in hook if ord(c) > 0x1F000]
        assert len(emojis) <= 2, f"Hook {idx} contains more than 2 emojis: {len(emojis)}"
        print(f"✓ Hook {idx} passed ({length} chars, {len(emojis)} emojis): '{hook}'")

    print("\n✓ All hooks successfully passed character and emoji constraints.")

if __name__ == "__main__":
    validate_copywriting()
